Project screenshots.

Drop a file here named to match the `shot` field in src/data/projects.js —
forge.jpg, lawtune.jpg, equilibrium.jpg and so on. A card with no file simply
renders without an image rather than showing a broken one.

Guidance:
  - 16:10 or thereabouts. The card crops to 16:10 and centres.
  - 1600px wide is plenty; anything larger is wasted bytes.
  - JPEG at ~80 quality. These are screenshots, not photographs.
  - Show the product doing something. A dashboard with real numbers on it
    persuades; a logo on a landing page does not.
